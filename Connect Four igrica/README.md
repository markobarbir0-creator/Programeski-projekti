# Connect Four

Implementacija klasične igre Connect Four u programskom jeziku C++ koristeći biblioteku SFML 2.6.2 za grafičko sučelje.

**Značajke:**
- Grafičko sučelje izrađeno pomoću SFML-a
- Igra za jednog ili dva igrača
- Provjera pobjede na temelju povezanih žetona
- Organizacija koda kroz klase i zasebne datoteke

**Tehnologije:** C++, SFML 2.6.2, Visual Studio
