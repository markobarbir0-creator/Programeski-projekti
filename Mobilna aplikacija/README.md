# Mobilna aplikacija – To-Do

Mobilna aplikacija za upravljanje zadacima, razvijena pomoću React Nativea i Expo okruženja.

**Značajke:**

- Interaktivno korisničko sučelje
- Razvoj aplikacije za mobilne uređaje

**Tehnologije:** React Native, Expo, TypeScript
